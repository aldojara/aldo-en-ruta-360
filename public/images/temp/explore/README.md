# Imágenes Temporales para la Sección Explorar

Este directorio contiene los recursos visuales temporales utilizados en el prototipo de la página **Explorar**. Ninguna de estas imágenes representa ubicaciones geográficas oficialmente validadas ni definitivas para el proyecto "Aldo en Ruta".
